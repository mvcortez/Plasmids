This is a repository of computer programs used in the simulations in the paper "Plasmid clustering slows redistribution driving a trade-off between growth and plasmid stability"

1. main.py  - the main skeleton program for implementing the nonhomogeneous CTMC; records only the last 20 cells in the simulations; ends only when plasmid loss occurs and outputs loss probability (1/length of lineage)
2. short_sims.py - similar to main.py but runs lineage only for a fixed number of cells; records all information about simulated cells in the lineage  
3. Lineage simulation and characterization: contains the program for the visualization of lineage simulations
4. ODE analog model: contains the program corresponding to the deterministic ODE analog of the stochastic model
5. Parameter fitting:
          - Clustering parameter: contains the programs for implementing the ABC algorithm for inferring the clustering parameters
          - Replication parameter: contains the programs for implementing the ABC algorithm for inferring the replication parameters
6. Supplementary Simulations: contains additional programs and Jupyter notebooks for supplementary numerical experiments and analyses presented in the paper and Supplementary Information. These include:
          - Comparisons of the binomial and no-clustering models
          - Analyses of the effects of clustering on population variance and inheritance asymmetry
          - Analyses of the combined effects of plasmid copy number and generation time on plasmid-loss probability
          - Additional simulations and analyses exploring the effects of model parameters on plasmid inheritance, clustering, and plasmid stability  

Notes on Required Data not uploaded in repository:
1. lineage_tau30.pkl - can be generated using the Lineage code
2. replication.pkl - can be generated using the “effects of clustering on variance” code
3. cluster.pkl - can be generated using short_sims.py and renaming the output accordingly. Set the replication parameters to tau=30.
4. data for Loss_vs_division - plasmid loss can be generated by running main.py with multiple repeats and parsing the reported loss probability. Corresponding parameters are given in Table S2 in the Supplementary Information. Name collated data accordingly.  
5. data for cross analysis - plasmid loss can be generated by running main.py with multiple repeats and parsing the reported loss probability. Corresponding parameters are given in Table S2 and S3 in the Supplementary Information. Name collated data accordingly.
6. data for Binomial_clustering_off_comparison.ipynb - old_cluston.csv and old_cluston.csv can be generated from Analyze_beta.ipynb
7. data for Analyze_ beta (segrated and free plasmids) - can be generated using short_sims.py by changing the corresponding beta parameterparameter. Rename the output pkl file accordingly.
8. data for Analyze_ beta (plasmid loss) -  plasmid loss can be generated by running main.py with multiple repeats (per beta or sigma parameter) and parsing the reported loss probability. Name the collated loss data accordingly.
